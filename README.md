# Vivan Bubble - Ball Sort Puzzle Game

A sleek, responsive, and lightweight web-based color ball sorting puzzle game featuring **99 progressive levels**, move tracking, undo support, and interactive level replay.

---

## 🎮 Features

- **99 Progressive Levels:** Difficulty scales from simple 3-tube beginner setups to complex multi-color challenges.
- **Interactive Level Selector:** Click on the center level indicator (`Level X/99`) anytime to view and replay any cleared level.
- **Undo System:** Fast, state-driven undo button on the top-right corner to revert unwanted moves.
- **Clean Branding:** Static **Vivan Bubble** logo on the top-left corner.
- **100% Offline Ready:** Built with pure HTML5, CSS3, and Vanilla JavaScript—no server required.
- **Touch & Click Friendly:** Optimized for both mobile smartphones and desktop web browsers.
